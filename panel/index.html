Connect a node

A node is a VPS running the MSOP Panel backend. Your servers live there — this site is the remote control.

  1. On an Ubuntu VPS, run:curl -fsSL https://raw.githubusercontent.com/MeowSamOPDZN/msop-panel/main/install.sh | sudo bash
  2. Update it once for remote access:cd /opt/msop-panel && sudo ./update.sh
  3. Copy the API token printed at the end of the install (or run node server/setup.js --show-token on the VPS).
  4. Press Connect node below and paste the node's address + token.
